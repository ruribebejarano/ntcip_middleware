# Evidencia para la tesis

Guardar aquí **el mismo día** capturas, fotos y logs que respaldan cada hito.
Nombre: `AAAA-MM-DD_<componente>_<que-muestra>.<ext>`, por ejemplo
`2026-10-14_agente_snmpset-1211.png` o `2026-10-20_broker_conexion-rechazada-sin-cert.png`.

Cada archivo debe estar citado en una entrada de `docs/bitacora/`.
No editar ni recortar los originales: si hace falta una versión para la tesis,
guardar una copia con sufijo `_tesis`.
